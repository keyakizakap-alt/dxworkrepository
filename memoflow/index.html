クラウド同期

複数端末でメモを同期するには、無料の Supabase プロジェクトを1つ用意し、 その接続情報をここに入力してください。データはお使いの Supabase プロジェクトにのみ保存され、 Project URL と anon key はこのブラウザにだけ保存されます（リポジトリには含まれません）。

初めての方向け: Supabase プロジェクトの準備手順
  1. supabase.com で無料アカウントを作成し、新規プロジェクトを作成
  2. 「Project Settings → API」で Project URL と anon public key をコピーし、上に貼り付け
  3. 「SQL Editor」で以下を実行してテーブルを作成
create table if not exists public.memoflow_workspaces (
  user_id uuid primary key references auth.users(id) on delete cascade,
  data jsonb not null,
  device text,
  updated_at timestamptz not null default now()
);

alter table public.memoflow_workspaces enable row level security;

create policy "select own workspace" on public.memoflow_workspaces
  for select using (auth.uid() = user_id);
create policy "insert own workspace" on public.memoflow_workspaces
  for insert with check (auth.uid() = user_id);
create policy "update own workspace" on public.memoflow_workspaces
  for update using (auth.uid() = user_id);

alter publication supabase_realtime add table public.memoflow_workspaces;

「Authentication → Providers」で Email を有効にし（デフォルトで有効）、 「Authentication → URL Configuration」の Redirect URLs に、このアプリを開くURLを追加してください。 ログインはパスワード不要の「マジックリンク」方式です。

メールアドレス宛にログイン用のリンクを送ります。パスワードは不要です。
