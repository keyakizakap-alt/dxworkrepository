# NTTグループ 法令・案件適合性 判定bot(Dify)

検討中の案件が、NTT法・電気通信事業法・労働安全衛生法・労働基準法・建設業法・下請法(取適法)
などの法令、および「NTTグループで実施可能な事業範囲」に関連するかを判定する Dify チャットボットです。

- ファイル: [`ntt-compliance-bot.yml`](./ntt-compliance-bot.yml)
- アプリ種別: Chatflow(`mode: advanced-chat`)
- 構成: 開始 → 判定LLM → 回答

## インポート手順

1. Dify にログイン → 「アプリを作成」→ **DSLファイルをインポート**。
2. `ntt-compliance-bot.yml` をアップロード。
3. **モデルの設定**:このDSLは `openai / gpt-4o` を指定しています。
   利用中のプロバイダに合わせて「判定LLM」ノードのモデルを変更してください
   (例: Azure OpenAI、Anthropic Claude など)。API キーは Dify の
   「設定 → モデルプロバイダー」で登録します。
4. 右上の **公開** を押して利用開始。

## 使い方

チャット欄に案件・業務内容を貼り付けると、以下の形式で判定を返します。

- 総合判定(関連あり / 一部関連 / 関連なし / 要確認)
- 該当が想定される法令・観点
- 判断の根拠 / リスク・留意点 / 推奨アクション / 追加で確認したい情報

## ナレッジベース(RAG)を追加する場合(推奨)

本DSLは法令の要点をシステムプロンプトに内蔵していますが、社内規程・法令原文・
過去案件の判定事例などの**関連資料**を追加すると精度が上がります。

1. Dify の「ナレッジ」で資料(PDF/Word/テキスト等)をアップロードしてデータセットを作成。
2. アプリのオーケストレーション画面で **知識取得(Knowledge Retrieval)ノード** を
   「開始」と「判定LLM」の間に追加し、作成したデータセットを紐付け。
3. 「判定LLM」ノードの **コンテキスト** に知識取得ノードの出力を設定。
   (システムプロンプト末尾に「提供されたコンテキストを最優先の根拠とする」旨を記載済み)

> DSLでデータセットIDを直接埋め込むと環境依存になるため、資料の接続はDify上で行う構成にしています。

## 注意事項

本botの回答は一般的な情報提供であり、法的助言ではありません。
最終的な適法性・実施可否の判断は、必ず法務・コンプライアンス部門にご確認ください。
