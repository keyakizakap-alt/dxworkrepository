# アイデア出しと絞り込み

ニュアンス税関（社会課題ハッカソン）で 75 案から本命 1 案を選んだときの方法。
**量を出す工程と、落とす工程を分ける**のが要点。

## 1. 量を出す — レンズを割り当てる

1 人（1 エージェント）で考えると発想が偏る。**異なるレンズを 10 個割り当てて並列に出す。**
実際に使ったレンズ：心理・行動経済 / 実務制約（ビザ・時差・リージョンロック）/ 政策・ソフトパワー /
実在事例分析 / 社会運動論 / 実装現実主義（期間内に作れるか・公開 API はあるか）/ 経済（手数料・為替）/
人道 / 言語文化 / **悪魔の代弁者（テーマ自体の危うさを暴く）**。

最後の 1 つは必ず入れる。全員が同じ方向を向いた案は、たいてい前提を疑っていない。

**落とした案も全量保存する。** 後から「なぜあれを採らなかったか」を必ず聞かれる。

## 2. 落とす — ゲートを順に通す

スコアで足し算する前に、**満たさなければ即失格のゲート**を先に通す。

| ゲート | 問い |
|---|---|
| **テーマ適合** | テーマの要素を取り除いてもプロダクトが成立するなら、それはこのテーマの案ではない |
| **AI 依存** | AI を取り除いても成立するなら、それは AI プロダクトではない |
| **倫理** | 誤判定が誰かへの攻撃になりうるか。善意にも悪意にも等しく効く道具になっていないか |
| **実現性** | 期間内に作れるか。信頼担保（なりすまし・持ち逃げ）を解けるか |
| **収益性** | デモは最高でも、誰も金を払わない案は残さない |

この 2 つ目までを同時に通したとき、**「テーマ依存と AI 依存がトレードオフになっている」**という
構造が見えた。深くテーマに食い込む案は AI が装飾で、AI が本体の案はテーマが薄い。
**両方が抜けない唯一の領域**が本命だった。

同じ中核能力を使う案が複数残ったら、**統合できないかを見る**（発信側と受信側で 1 つのプロダクトになった）。

## 3. 評価軸は改訂してよい。ただし経緯を残す

軸は 5 回変わり、**各改訂で首位が入れ替わった**。だから軸の改訂履歴そのものが判断材料になる。

| 回 | 追加した軸 | 起きたこと |
|---|---|---|
| 1 | デモ映え | 収益モデルのない案が上位に |
| 2 | 倫理・実現可能性・ビジネス | 動員最適化系・工作検知系が倫理で失格 |
| 3 | 収益性・社会課題性・技術・勝率 | 首位が入れ替わる |
| 4 | テーマ適合ゲート | 前回首位が失格 |
| 5 | AI 依存ゲート | 前回首位は AI が装飾と判明 |

**失格にした案は理由付きで残す。** 「倫理ゲート／実現性ゲート／収益性ゼロ」のどれで落ちたかを書く。

## 4. 課題の語り方 — 内輪の語彙から始めない

初期案は、専門語彙（「地雷」「解釈違い」「同担拒否」）の説明が課題説明の前提になっており、
**聞き手がその文化を知らないと刺さらない**という致命的な弱点があった。

組み替え方：

1. 前提知識の要らない事実から始める（「日本のコンテンツが史上最大の規模で海外に出ている」）
2. 構造的な問題を 1 文で言う（「機械翻訳は感情の極性と警告を構造的に壊す」）
3. **実例 1 つで伝える**（「かわいすぎて死んだ 💀」→ *"so cute I died 💀"* → 脅迫として着弾する）

内輪の語彙は、課題が伝わったあとに「これが競争力の源になる知識資産である」と説明する順にする。
