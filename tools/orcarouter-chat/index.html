接続設定

API キーはこのブラウザの localStorage にのみ保存され、どこにも送信されません（LLM プロバイダへのリクエストを除く）。 リポジトリにキーがコミットされることはありません。

ブラウザから直接 API を呼ぶため、プロバイダ側が CORS を許可していないと失敗します。 403 や CORS エラーが出た場合は、同梱の中継サーバを起動して Base URL を http://localhost:8787/v1 に向けてください: node tools/orcarouter-chat/scripts/proxy.mjs
